arcadeVFE v.1.2.0
To update from version 1.1, right click on the zip file, choose Properties, 
check the Unblock checkbox at the bottom, then click Apply. After doing this,
extract all files and folders from the zip into your 1.1 folder and allow
Windows to overwrite all files. No user files should be overwritten in the
process with the following two possible exceptions.

Note 1: If you made any changes to the machine directory, backup the file
.\Arcade\Arcade Time Capsule 3.6.Locations.ini prior to overwriting files, 
and restore when completed.

Note 2: If you made any changes to the Command template list, backup the
file .\Config\templates.json prior to overwriting files, and restore when 
completed.

* Now possible to map keyboard keypresses to GameInfo navigation actions.
* Removed lower case letters from "Map a keypress" since they're redundant.
* Improved algorithm to deal with a case where quickly moving between.
  machines with GameInfo enabled could cause loss of state.
* Provide a method to specify image order in GameInfo.
* Added support for ctrl, alt, shift, win keypress combos.
* Game data updates, and added a large number of new images.
* Added game logo to GameInfo startup.
* Added splash screen at startup.
* Send discrete up/down events when mapping buttons to keypresses.
* Added rom's MAME version above the rom list.
* Warn user to restart the application when toggling the "Operate only 
  when arcade is running" setting.
* Added WS_EX_NOACTIVATE to GameInfo to better protect from mouse clicks.
* "Copy ROMs" function now copies chd folders as well.
* Limit image scaling for low res images in GameInfo to improve quality.
* Clear the current rom when arcade exits. 
* Tooltip help updates.
* Added additional startup logging and auditing.
* Documentation updates.
* Some general code clean-up.

arcadeVFE v.1.1.0
* Added a third command line config option.
* Added game information overlay
* Added initial setup dialog
* Added rom auditing feature
* Added rom copying feature
* Added machine location editor
* Cleaned ROM list and added rom information to the drop down
* Added support for keypresses to be mapped to game controller buttons
* Only display command columns in the action list if needed. 
* Reset profile load suppression on application exit.
* Blocked running of null button actions which caused side effects.
* Improved method of changing rom file access time to address locks on larger files.
  (caused profile switching to fail after playing large rom games)
* Raised pitch of error double-beep (was hard to hear).
* Beep on profile change off by default.
* Error message enhancements.
* Many bug fixes.
