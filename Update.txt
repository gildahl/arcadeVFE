v1.1.1
To update from version 1.1, right click on the zip file, choose Properties, 
check the Unblock checkbox at the bottom, then click Apply. After doing this,
extract all files and folders from the zip into your 1.1 folder and allow
Windows to overwrite all files. 

If you had made any changes to the machine directory, backup the file
.\Arcade\Arcade Time Capsule 3.6.Locations.ini prior to overwriting files, 
and restore when completed.

* Added support for ctrl, alt, shift, win key combos.
* Game data updates and added many missing images.
* Added game logo to GameInfo startup.
* Send discrete up/down events when mapping buttons to keypresses.
* Add rom's MAME version to rom list.
* Suggest restart after changing arcade running setting.
* Tooltip help updates.
* Documentation updates.
* Some general code clean-up.
